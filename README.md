# Create and test a Grails 5 TagLib; integrate the Trix WYSWYG editor

This repository contains the worked sample app for the [Create and test a Grails 5 TagLib; integrate the Trix WYSWYG editor](https://grails.apache.org/guides/grails-taglib-wyswyg-trix/4/guide/index.html) guide on the Apache Grails site.

## Run the example

`./gradlew bootRun`

## Maintained at apache/grails-static-website

The guide narrative is maintained at https://github.com/apache/grails-static-website. Changes to the guide content go there; this repo holds the worked sample app only.
